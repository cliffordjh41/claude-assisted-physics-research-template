# sketch

Stage 0. Pictures as they arrived, in the words they arrived in,
before formalization.

One file per line of thinking, `sketch/<slug>.md`, dated sections
appended and never edited afterward. A sketch claims nothing, so
it cites nothing and owes no falsifier. It exists because the
first formalization of an intuition is usually wrong, and once
the formalization exists the original picture is unrecoverable --
the vocabulary overwrites it, and what gets defended afterward is
the frame rather than the idea.

When a frame is discarded, work restarts from here.
