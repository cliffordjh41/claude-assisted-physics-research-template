# notes.md template — required bibliographic fields by source type

Internal-only template. Lives outside the `<domain>/<author>/`
canonical pattern. Source filings in `library/` use this as the
field-list reference; `sources.md` points here.

## Required fields by type

- **Academic papers** — authors, title, journal, volume, pages,
  year, DOI, arXiv ID with version (`arXiv:2310.12345v2`).
- **Books** — authors/editors, title, publisher, year, edition,
  ISBN.
- **Pre-arXiv historical** — author, title, publisher/journal,
  year, page range.
- **Patents** — number, title, inventors, assignee, filing date,
  grant date, issuing office.
- **Court opinions** — case name, reporter citation, court, year.
- **Statutes** — title, code citation, section, year of last
  amendment.
- **Archival** — collection, holding institution, finding aid
  reference, item ID.
- **Web** — full URL, date of access, archived snapshot if
  available.

Incomplete citations are worse than missing ones.

## `notes.md` body — content discipline

Per `sources.md`:

- Bibliographic data block at the top (full citation per type
  above).
- Page/equation/paragraph/section numbers that are
  load-bearing.
- Extracted content: equations verbatim, passages with
  citation, doctrine paraphrased with citation, derivation
  steps in source's notation.
- One-line note on what this source is used for.
- Date of first read.
- Provenance footer: screenshots / scans the transcription
  draws from.

Not in `notes.md`:

- Re-narration of full table of contents.
- Material from other sources.
- The agent's interpretation or extension (lives in the
  journal of the body using the source).
